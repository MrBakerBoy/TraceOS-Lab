# TraceOS Lab Frontend

云原生 AI 辅助操作系统学习平台前端应用。

## 技术栈

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Monaco Editor

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm start
```

## Docker

```bash
docker build -t traceos-frontend .
docker run -p 3000:3000 traceos-frontend
```
